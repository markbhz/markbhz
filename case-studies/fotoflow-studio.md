# FotoFlow Studio

**Stage:** Validated prototype  
**Category:** Vertical SaaS · Documents · Portfolio  
**Source code:** Private

## Context

Independent photographers frequently manage leads, quotes, contracts, deliveries and portfolio updates using disconnected tools.

## Product

FotoFlow Studio explores a unified workspace for studio operations, guided commercial documents and portfolio publishing.

### Validated capabilities

- Responsive studio dashboard
- Quote builder with automatic totals and PDF output
- Contract wizard with editable clauses
- Visual photographer signature and A4 PDF generation
- Public-portfolio editor
- White-label visual settings

## My role

Product discovery, design-system consolidation, frontend implementation and visual verification of generated documents.

## Technical direction

React and TypeScript prototype with reusable design tokens and client-side document generation. Authentication, persistence, secure media uploads and specialized digital signatures remain future production work.

## Privacy

All displayed clients, contracts and business metrics are synthetic. The prototype does not process real personal data.
